# Как писать сцену

Фильм «Библия за 10 минут» — кинематографичная 3D-анимация на Three.js (r170), отрендеренная покадрово
в headless Chromium (SwiftShader, без GPU). Озвучка, субтитры, цитаты, HUD и рамка рисуются 2D-оверлеем
автоматически (`film/overlay.js`) — сцене нужно только **изображение**.

## Контракт

`film/scenes/<id>.js`, где `<id>` — из `data/timeline.json` (`scenes[].id`).

```js
export default function build({ THREE, lib, W, H, meta, SCALE }) {
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(38, W / H, 0.1, 3000);
  // ...строим всё один раз...
  return {
    scene, camera,
    update(t, S) { /* t — секунды от начала сцены. Ставим камеру, свет, анимацию. */ },
  };
}
```

- `meta` = запись сцены из `data/timeline.json`: `dur`, `cues` ({имя: секунда начала реплики}), `lines`
  (реплики с `start/end` и пословными таймингами `words`). Визуальные события синхронизируем с репликами через cues.
- **Детерминизм обязателен.** Кадры рендерятся в произвольном порядке разными процессами. `update(t)` должен
  выставлять ВСЁ состояние из `t` (никаких накоплений `x += dt`, никакого `Math.random()` — только `lib.rng(seed)`
  при построении). Uniform `time` у шейдерных объектов из lib выставляется ядром автоматически = t.
- `S.post` — грейдинг кадра, меняйте по вкусу: `exposure, bloom, bloomRadius, bloomThreshold, vignette, grain,
  sat, contrast, tint:[r,g,b], lift:[r,g,b], ca, flash` (flash 0..1 — белая вспышка).
- `S.fadeIn / S.fadeOut` (сек, по умолчанию 0.7) — затемнение на стыках сцен. `S.quote.y` (0..1) — где по
  вертикали в кадре стоит крупная цитата (по умолчанию 0.5). `S.k('cue', dur, offset)` → 0..1 рампа от реплики;
  `S.since('cue')` → секунд с начала реплики.
- Кадр 1920×1080, но сверху и снизу по 116 px чёрные полосы (кинорамка 2.26:1) — **значимое держим в центральной
  полосе**. Левый верхний угол кадра занят HUD-плашкой (≈ 420×110 px) — не ставьте туда главное.
- Цитаты (реплики `v:"q"`) выводятся крупным белым курсивом по центру кадра — в эти моменты в центре должно быть
  спокойно/темнее (или сдвиньте `S.quote.y`), иначе текст не читается. Не делайте белый пересвет за текстом.

## Стиль (держим единым по всему фильму)

- Тёплый кинематографичный свет, туман/атмосфера, глубина, мягкий блум, силуэты против света. Референс —
  современная анимационная короткометражка: плавные медленные проезды камеры, крупные/средние/общие планы,
  2–4 «кадра» (смены ракурса) на сцену, привязанных к репликам через cues.
- Люди — стилизованные фигуры `lib.figure()` (одежда-балахон, капюшон, без лиц), чаще силуэтами и на
  среднем/дальнем плане. Иисуса не показываем крупно с лицом — фигура в светлом, на расстоянии / со спины.
- Не пересвечивайте: солнце в кадре — да, но экспозиция ≤ 1.1, `sunGlow` ≤ 1.2. Белые вспышки — коротко.
- Никакого текста в 3D, кроме уместного (скрижали и т.п.) — текст делает оверлей.

## Производительность (важно: CPU-рендер!)

- Бюджет ≈ 1 с на кадр 1440×810. Не больше ~150k треугольников, ~30k частиц, ≤ 2 тени (`castShadow`), без
  тяжёлых циклов в `update`. Геометрию/материалы создаём в `build`, в `update` только трансформации и uniforms.
- Лучше: туман + силуэты + свечение, чем много полигонов.

## Что есть в `lib` (film/lib.js)

Математика: `clamp, lerp, smooth, ease, easeOut, easeIn, ramp(t,a,d), win(t,a,b,fin,fout), rng(seed), noise2, fbm`.
Объекты: `skyDome({top,horizon,bottom,sunDir,sunColor,sunSize,sunGlow,stars})` (меняйте `sky.u.*.value`),
`starfield`, `motes({kind:'dust'|'embers'|'snow'|'rise'})`, `fire`, `rain`, `ocean` (u.amp, u.choppy, u.foam, цвета),
`terrain({heightFn,colorFn})`, `figure({height,robe,skin,hood,staff,glow})` + `walkPose(fig, phase)`,
`glow(color,size)`, `lightBeam`, `cloudLayer` (+ `.drift(t)`, `.setOpacity(k)`), `textPlane`, `canvasTexture`,
`cameraPath(camera, [[t,[x,y,z],[lookX,lookY,lookZ]],...], t)`, `handheld(camera, t, amt)`.
Можно писать свои ShaderMaterial (есть `lib.GLSL_NOISE`). Пример готовой сцены — `film/scenes/creation.js`.

## Проверка

```bash
cd bible-film
node tools/render.mjs --preview s<сек_от_начала_фильма>,s...,s... --out /tmp/<ваша_папка> --sheet sheet.jpg
```
Время — **глобальное** (начало сцены = `scenes[i].start` в `data/timeline.json`). Смотрите `sheet.jpg`
(Read-инструментом), правьте, повторяйте. Ошибки страницы печатаются как `[pageerror]`.
Время рендера кадра печатается — держите ≲ 1500 мс (первый кадр сцены дольше — это сборка).
