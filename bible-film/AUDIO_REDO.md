# Переделка звука через Higgsfield 🎙️

Задача: заменить офлайн-голос RHVoice (звучит роботом) и синтезированную музыку на качественные —
через коннектор **Higgsfield**. Картинку не перерендериваем (≈4 ч на CPU).

## Что уже есть
- Видео 1080p (картинка готова): `bible-film/video/Bible_15min_1080p.mp4` (Git LFS) — берём только видеодорожку.
- Тексты всех 111 реплик, тип (рассказчик `n` / цитата `q`) и **окна времени** каждой реплики:
  `data/timeline.json` → `scenes[].start + lines[].start / end`. Сценарий: `data/script.json`.
- Звук: `tools/sound.py` — атмосферы, эффекты, сведение 5.1 + стерео, дакинг под голос, отчёт SNR по репликам.
  Голос читается из `audio/lines/<scene>_<NN>.wav` (`lines[].wav` в timeline.json).

## План
1. **Голос**: сгенерировать в Higgsfield все реплики по-русски — глубокий тёплый мужской голос рассказчика;
   цитаты (`v: "q"`) — тем же голосом, медленнее и торжественнее. Сохранить в `audio/lines/` с теми же именами.
2. **Подгонка под картинку**: субтитры и сюжетные события уже «зашиты» в видео, поэтому каждая новая реплика
   должна уложиться в своё окно `start…следующая реплика`. Если длиннее — `ffmpeg atempo` (≤ 1.12×),
   если сильно длиннее — перегенерировать с более быстрым темпом. Начало реплики = прежнее `start`.
3. **Музыка/фон**: если Higgsfield умеет музыку — сгенерировать оркестровые треки по сценам (настроения — в
   комментариях партитуры `tools/sound.py`), заменить ими шину `mus`; атмосферы/эффекты можно оставить.
4. Пересобрать звук: `python3 tools/sound.py` (проверить отчёт: каждая реплика ≥ 12 дБ над фоном).
5. Смешать с видео: видеодорожка из LFS-файла + `audio/mix.wav` (стерео, по умолчанию) + `audio/mix51.wav` (5.1),
   см. `tools/assemble.sh` (там склейка из сегментов — здесь вместо этого `-i video/Bible_15min_1080p.mp4 -map 0:v`).
6. Залить новую версию в LFS (`bible-film/video/`), дать ссылку.
